# शाही शुभ विवाह निमंत्रण — देवराज सिंह चौहान संग मधु कंवर
### The Royal Rajputana Wedding Experience | Mewar, Rajasthan

A bespoke, production-ready, ultra-premium interactive royal wedding invitation web experience designed for the distinguished Rajput Chauhan family of Mewar, Rajasthan.

---

## ⚜ विशेषताएं (Key Features & Highlights)

1. **शाही पर्दा प्रवेश (Scene 1 — The Royal Velvet Curtain Entrance):**
   - Full-screen heavy royal red velvet curtains with realistic fabric folds, shadows, and golden lace.
   - Traditional top valance pelmet with hanging golden ornamental tassels.
   - Central authentic royal **Chauhan Family Coat of Arms** (*"चहुदिशाण चक्रवर्ती चवहाण — आशापुरा सहाय विच्छय"*).
   - Auspicious invocation: `|| श्री गणेशाय नमः ||`, `पधारो सा...`.
   - **"शुभ निमंत्रण खोलें"** button with realistic cloth parting animation and celebratory royal flower petal shower (`canvas-confetti`).

2. **शाही पत्रिका अनावरण (Scene 2 — The 3D Royal Invitation Card Reveal):**
   - Floating three-dimensional luxury kankotri card over palace courtyard atmosphere.
   - Antique ivory parchment finish, gold-foil embossing, and traditional Rajputana miniature art borders.
   - Closed cover with *"✨ स्पर्श कर निमंत्रण खोलें ✨"*.
   - Unfolds in 3D perspective to reveal the couple's details and sacred tithi:
     - वर: आयुष्मान देवराज सिंह चौहान (भमसा)
     - वधू: आयुष्मति मधु कंवर (मोना)
     - शनिवार, 21 नवम्बर 2026 (वि.सं. 2083 — कार्तिक सुदी द्वादशी).

3. **सिनेमैटिक मुख्य प्रांगण (Scene 3 — Cinematic Royal Wedding Homepage):**
   - Carved Jharokha archways and sandstone-gold aesthetics.
   - Live real-time countdown timer to 21 November 2026 (दिन, घंटे, मिनट, सेकंड).
   - Quick navigation action pills (कार्यक्रम, शुभ स्थल, RSVP, मूल पत्रिका PDF).

4. **मांगलिक कार्यक्रम समय-सारिणी (Scene 4 — Interactive Wedding Events):**
   - All 8 authentic traditional ceremonies extracted strictly from the wedding card:
     1. **छोटा व बड़ा विनायक** (17 Nov 2026, 10:15 AM)
     2. **मंगल कलश** (19 Nov 2026, 5:00 PM)
     3. **थम्ब रोपण** (20 Nov 2026, 7:00 AM)
     4. **मायरा दस्तूर** (20 Nov 2026, 1:00 PM)
     5. **हल्दी दस्तूर** (20 Nov 2026, 4:00 PM)
     6. **महिला संगीत** (20 Nov 2026, 7:00 PM)
     7. **निकासी** (21 Nov 2026, 5:00 AM)
     8. **पाणिग्रहण संस्कार** (21 Nov 2026, 9:00 AM)
   - Each event features custom traditional vector iconography, tap-to-expand cultural significance notes, and an instant **"गूगल कैलेंडर में जोड़ें"** reminder.

5. **राजपूती परम्परा एवं परिवार (Scene 5 — Family Lineage & Heritage):**
   - वर पक्ष (ठि. फलीचड़ा, मेवाड़, हाल मु. भीलवाड़ा) & वधू पक्ष (ठि. लागच, हाल मु. चन्देरिया).
   - मुख्य आमंत्रक / उत्तराकांक्षी (ठा. राम सिंह चौहान, कुं. गजेन्द्र सिंह चौहान, कुं. पूरण सिंह चौहान, भं. दिगपाल सिंह चौहान).
   - स्वागताकांक्षी (रेणुका कंवर) & दर्शनाभिलाषी.
   - मीठी मनुहार (दादोसा एवं छोटे भाई हेतु स्नेहिल मनुहार).
   - आत्मीय सम्बन्धी व विशेष आग्रह (ननिहाल पक्ष, साडू जी पक्ष, जवाई पक्ष, विशेष आग्रह).

6. **शुभ स्थल एवं मार्ग (Scene 6 — Venue & Directions):**
   - **पायल रिसोर्ट**, सरस डेयरी के पास, भीलवाड़ा, राजस्थान.
   - Direct Google Maps Navigation: [https://maps.app.goo.gl/5yyKhDfyXap6MiHp9](https://maps.app.goo.gl/5yyKhDfyXap6MiHp9).
   - एक-टैप पता कॉपी एवं सहायता फोन कॉल सुविधा.
   - राजकीय प्रीतिभोज एवं बारात प्रस्थान का स्पष्ट उल्लेख.

7. **आदर सहित WhatsApp RSVP (Scene 7 — Interactive Royal Reply Flow):**
   - Guest name, attendance status, member count, and personalized blessings for the couple.
   - Deep-linked directly to **+91 6377273385** with a pre-filled formal Hindi message.

8. **शाही विदाई एवं आभार (Scene 8 — Farewell & Controls):**
   - "आपकी गरिमामयी उपस्थिति एवं शुभाशीर्वाद की अभिलाषा में — समस्त चौहान परिवार — पधारो सा".
   - "पुनः निमंत्रण देखें" (replays the curtain entrance), "मूल पत्रिका डाउनलोड", and floating "पुष्प वर्षा" button.

9. **राजकीय संगीत प्रणाली (Audio Architecture):**
   - Begins playback strictly upon user interaction (tapping "शुभ निमंत्रण खोलें").
   - Restrained ~30% volume with gentle fade-in and fade-out.
   - Floating music controller with animated soundwave equalizers and mute/unmute toggle.
   - Respects user preference via `localStorage`.
   - Auto-pauses on browser tab visibility changes.
   - Graceful Web Audio API Tanpura drone / temple bell harmonic fallback if an audio file is missing or loading.
   - User-supplied audio placed directly in `public/audio/wedding-music.mp3`.

## 🛠️ तकनीकी संरचना (Technical Stack)

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS with custom royal Rajputana palette (`#650F1C`, `#340A13`, `#C7A15A`, `#F7F0E2`, `#D9B995`, `#211B19`)
- **Animations:** Framer Motion + Web Audio API + Canvas Confetti
- **Typography:** Noto Serif Devanagari, Rozha One, Tiro Devanagari Hindi, Cinzel

## 🚀 लोकल रन एवं डिप्लॉयमेंट (How to Run & Deploy)

### Local Development:
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build:
```bash
npm run build
```
The output directory `dist/` is 100% static and ready to deploy on **Vercel**, **Netlify**, **GitHub Pages**, or any web hosting server.
